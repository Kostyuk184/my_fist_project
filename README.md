# Password Generator:
 — Простой и надежный генератор паролей, который помогает создавать сложные комбинации символов для защиты ваших аккаунтов.

# Возможности:
 — Настройка длины: Генерация паролей от 8 до 128 символов.
Гибкость: Возможность включать/отключать:
 — Заглавные буквы (A-Z)
 — Строчные буквы (a-z)
 — Цифры (0-9)
 — Специальные символы
