# my_fist_project
# Password Generator:
 — Простой и надежный генератор паролей, который помогает создавать сложные комбинации символов для защиты ваших аккаунтов.

# Возможности:
 — Настройка длины: Генерация паролей от 8 до 128 символов.
Гибкость: Возможность включать/отключать:
 — Заглавные буквы (A-Z)
 — Строчные буквы (a-z)
 — Цифры (0-9)
 — Специальные символы

# Что мне для этого нужно:
1. Криптографически стойкий источник случайности — не Math.random() в JS или random в Python, а crypto.getRandomValues() / secrets модуль.
2. Настраиваемая длина — минимум 8–16 символов по умолчанию.
3. Набор символов — заглавные, строчные, цифры, спецсимволы (опционально).
4. Гарантия наличия каждого выбранного типа символов (если пользователь включил категорию).
5. Исключение похожих символов (0/O, 1/l/I) — опционально.
6. Никакой передачи пароля на сервер — генерация только локально.

# Минимальная архитектура
— Входные параметры:
· длина (12–64)
· чекбоксы: строчные / заглавные / цифры / спецсимволы
· опции: исключить похожие, исключить неоднозначные

— Алгоритм:
1. Собрать пул символов из выбранных категорий.
2. Проверить, что длина ≥ количества выбранных категорий.
3. Сгенерировать пароль через CSPRNG.
4. Гарантировать по одному символу каждой категории (взять случайные позиции).
5. Перемешать результат (Fisher–Yates с CSPRNG).
